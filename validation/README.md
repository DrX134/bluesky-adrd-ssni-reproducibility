# Human validation

The public ratings-only file contains no post text. It includes the pair identifier, cosine similarity, prespecified similarity stratum, and the two independent blinded binary ratings. This is sufficient to reproduce the reported inter-rater agreement, Cohen’s kappa, and reviewer-specific stratum/cutoff summaries.

The actual rating task was performed on a blinded file that omitted cosine-similarity scores and sampling strata. The pair sampling itself can be reconstructed from Notebook 03 when the frozen Notebook 01 outputs are available. No consensus adjudication was used in the final manuscript analysis.
